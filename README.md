# 🚀 Prisma Press - Backend API

A scalable RESTful API built with **Node.js**, **Express.js**, **TypeScript**, and **Prisma ORM** using a **PostgreSQL** database. Designed for modern content management and blogging platforms, providing authentication, role-based access control, and data management.

---

## ✨ Features

- 🔐 **Authentication & Authorization:** Secure user registration, JWT login (HTTP-only cookies/Bearer tokens), and refresh token rotation.
- 👥 **User Management & Profiles:** Role-based permissions (User, Author, Admin) and profile updates.
- 📝 **Post Management:** Complete CRUD operations for blog posts with category tags, views tracking, and publication statuses (Draft, Published, Archived).
- 💬 **Comment System:** Post discussions with comment creation, user replies, and admin moderation features.
- 🗄️ **Database & ORM:** Type-safe database queries and migrations using Prisma ORM with PostgreSQL.

---

## 🛠️ Tech Stack

- **Runtime:** Node.js
- **Framework:** Express.js
- **Language:** TypeScript
- **ORM:** Prisma ORM
- **Database:** PostgreSQL
- **Authentication:** JSON Web Tokens (JWT) & bcrypt
